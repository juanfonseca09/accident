# Análisis de Siniestros de Tránsito en Uruguay

Este proyecto analiza datos de fallecidos en siniestros de tránsito en Uruguay con el objetivo de identificar patrones temporales, geográficos y demográficos mediante técnicas de análisis de datos y visualización interactiva.

## Tecnologías
- Python
- Pandas
- SQLite
- Matplotlib
- Power BI
- DAX
- Power Query

## Qué hace
- Limpieza y transformación de datos
- Extracción de variables temporales
- Análisis mediante consultas SQL
- Generación de visualizaciones y KPIs
- Construcción de dashboard interactivo en Power BI

## Dashboard en Power BI
Se desarrolló un dashboard interactivo para explorar:
- Tendencias de fallecidos por mes
- Distribución por sexo
- Análisis por departamento
- Fallecidos por hora
- KPIs de casos totales y máximos mensuales
- Filtros dinámicos por año y variables demográficas

## Resultados
Se generan visualizaciones sobre:
- Fallecidos por mes
- Top departamentos con más casos
- Fallecidos por hora
- Distribución por sexo
