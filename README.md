# Análisis de Siniestros de Tránsito en Uruguay

Este proyecto analiza datos de fallecidos en siniestros de tránsito en Uruguay con el objetivo de identificar patrones temporales y geográficos.

## Tecnologías
- Python
- Pandas
- SQLite
- Matplotlib

## Qué hace
- Limpieza y transformación de datos
- Extracción de variables
- Análisis mediante consultas SQL
- Generación de visualizaciones

## Resultados
Se generan 4 gráficos:
- Fallecidos por mes
- Top departamentos con más casos
- Fallecidos por hora
- Distribución por sexo

## Cómo ejecutar

```bash
pip install pandas matplotlib
python script.py
